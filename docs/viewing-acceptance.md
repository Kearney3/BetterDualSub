# 观看体验升级验收

## 2026-10-22 可靠性与性能优化

- `.movpkg` 元数据在整数毫秒转换前检查时间与累计范围，异常轨道不会触发数值溢出；本地字幕读取最多接收 20 MiB 加一个用于判定超限的字节。
- 播放协调模块由应用和测试共同使用：首次监听报告确认连接，5 秒无响应后进入失败状态，以 2、4、8、16、30 秒退避重试。切换目标、新报告或重启会使旧查询失效；休眠冻结时钟，唤醒重新连接。
- 本地文件和观看历史恢复在后台解析，取消会传递给工作任务，结果写入前检查加载代次。
- 暂停时停用字幕定时器；隐藏时降为 1 Hz；锁定或隐藏浮层时停用鼠标轮询。屏幕、Space 和显示设置变化驱动定位，移除 0.5 秒轮询；相同文本与样式跳过富文本渲染。
- 观看历史缓存已序列化的字幕，未变化的快照不重写磁盘；采用版本化归档并兼容原数组格式。总容量为 100 MiB，优先淘汰旧记录，单条超限、损坏记录或未知格式版本不会覆盖已保存数据。
- 快捷键与主线程通知的隔离问题已修复；应用启用完整并发检查，仍使用 Swift 5 语言模式。Translation 的 `prepareTranslation` 和 `translations` 调用仍有 3 处跨隔离警告，Swift 6 应用迁移尚未完成；没有通过抑制检查消除这些警告。
- PR CI 增加 Debug/Release 构建；CI 与发布构建均要求使用已提交的依赖锁定文件。

本地验证：`swift test` 执行 63 项，62 项通过，1 项真实电影下载测试因未提供链接而跳过；Debug、Release 构建通过。使用实际构建出的 MediaRemoteAdapter 和新的协调模块运行只读探针，收到真实的 `noMedia` 报告并完成握手；探针未播放、暂停或跳转任何媒体。

尚未完成：真实 TV.app 整片观看、字幕浮层交互回归、外接屏拔插、硬件能耗测量、翻译框架并发迁移，以及远程 CI。上述本地检查不代表这些项目已验收。

## 本机界面检查

| 场景 | 验收要求 |
| --- | --- |
| 首次使用 | 加载、播放器连接和浮层可见分别确认；未连接时不能误报完成 |
| 本地文件 | 粘贴路径或拖入一至两条字幕，正确分配第一、第二轨 |
| 链接 | 电影链接进入电影页；剧集、TV+ 或其他网站输入显示替代入口 |
| 最近观看 | 调整延迟，退出重开，恢复双轨与外观；不需要原始文件，不跳转视频 |
| 清除 | 移除一条不影响其他记录；清空需要确认，原始与导出文件保留 |
| 诊断 | 主动导出 JSON，检查不含字幕正文、片名、路径、来源链接或账号标识 |
| 翻译 | 源语言可修正；试译只预览；完整翻译可撤销第二轨替换；恢复后保留译文 |

## 真实播放与硬件验收（需要播放器和对应设备）

以下不能由单元测试或编译通过代替，每项应记录播放器、系统版本、影片版本、实际结果及失败原因。

- TV.app 连续观看一部电影，分别记录首次成功显示耗时、额外校准次数、丢失连接次数和是否完整看完。
- 暂停后继续、前后拖动、切换影片或剧集；字幕不继续跑旧时钟、不跟错播放器。
- 支持倍速的播放器切换速度，字幕与视频时间保持 1:1。
- 其他播放器抢占 Now Playing、关闭目标播放器、辅助进程退出、休眠与唤醒；状态可解释并能恢复。
- 普通窗口与原生全屏之间切换；浮层、悬停控制条与点击穿透保持可用。
- 外接显示器分别保存位置、字号；切换屏幕、拔插、分辨率变化与不同 Space，浮层始终处于可见区域。

- 已安装与未安装翻译语言、取消语言下载、翻译期间更换字幕、离开页面、取消后立即重试，均不覆盖后续字幕。
