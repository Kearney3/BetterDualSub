# 影片链接字幕下载改造与验证

验证日期：2026-10-11。原生 Swift 实现，无新增运行时依赖，无需 Python。

## 实现范围

影片页面链接 → 地区 storefront → Apple 配置及电影 API → iTunes 影片版本与 HLS 地址 → 外挂文字字幕语言 → WebVTT 分段 → 时间戳归一化、排序去重 → 两份 SRT 缓存 → 双轨字幕管理器。

下载窗口支持版本选择、语言选择、进度、取消和错误提示。只有所选字幕全部下载并保存成功后才替换当前字幕；失败或取消保留原字幕。账号标识不落盘，匿名请求优先，DSID 仅向两个指定的 iTunes 主播放列表端点发送。下载地址及重定向限定为 Apple HTTPS 域名。

双轨共用 TV.app MediaRemote 时间源。时钟按单调时间和播放速度计算，暂停、跳转时重新锚定；忽略其他播放器的时间。整体和第二轨额外偏移可分别调整。修复字幕换行显示和新增下载窗口干扰浮层定位的问题。

## 已验证

- Xcode 27.0：Release 正常应用和 Debug 独立测试应用构建成功。
- 12 个确定性 XCTest 通过，覆盖链接验证、SRT/WebVTT 解析、时间边界、重叠字幕、倍速/暂停/跳转、HLS 镜像、分段限制、时间戳映射与 33 位回绕、完整模拟 API 下载、DSID 约束及进行中的请求取消。默认另一个联网测试跳过。
- 实际香港区《Spider-Man: Into the Spider-Verse》电影页面：发现 30 条外挂字幕轨；成功下载 en-GB 1389 条和 cmn-Hans 1406 条字幕，末条结束时间分别为 6996538 ms 和 7007090 ms。未使用账号、Cookie 或 DSID。联网测试验证导出 SRT 可重新解析。
- 原生应用界面完成查找、默认选择英中两轨、下载及加载流程；核对缓存中的两份 SRT 与字幕数量。
- 原生界面按 Escape 取消下载，显示“已取消，当前字幕保留”。
- 最后复测修复 `@Published` 延迟字段在属性观察器中反复赋值导致的加载崩溃；重新下载并加载双轨成功，整体延迟输入 999999999 和第二轨输入 -999999999 分别稳定限制为 ±86400000 ms。无效影片链接显示错误并保留已加载双轨。
- Release 包的 `codesign --verify --deep --strict` 通过，第三方许可已包含在应用资源中；`git diff --check` 通过。
- 影片页面解析与电影资源路径研究见 `isubrip-download-research.md`。

## 验证边界

没有在实际 TV.app 播放影片时验收字幕浮层、暂停、拖动和倍速的完整同步效果；这些操作的时钟计算已有单元验证，但仍需播放器实测。没有验证需要 DSID 的真实付费资源；其请求范围及重试规则仅经过模拟测试。

部分影片的英文字幕为视频内嵌 CC，例如此次研究的《Interstellar》版本。此类字幕无外挂 URI，不在可下载轨道中。Apple TV+ 订阅专属影片、剧集，以及加密/不连续/字节范围/初始化映射字幕播放列表目前不支持。两个语言版本的剪辑差异不能仅靠同一时钟消除，需选择一致的影片版本并视情况调整偏移。
